# Kally V2 validator benchmark (Studio Dev prototype)

V2 replaces caller-supplied prediction reports with validator-executed scoring. It deliberately supports **only** `kally.linear.v1`: a binary linear classifier with 1–16 integer weights, a bounded integer bias, and at most 32 labeled examples. It does not run Llama, Docker, GLUE, ImageNet, or arbitrary checkpoint code.

The model is a UTF-8 JSON file such as:

```json
{"schema":"kally.linear.v1","weights":[2,-1],"bias":0}
```

The dataset is a UTF-8 JSON file such as:

```json
{"schema":"kally.dataset.v1","nonce":"0123456789abcdef0123456789abcdef0123456789abcdef0123456789abcdef","examples":[{"features":[2,0],"label":1},{"features":[-2,0],"label":0}]}
```

The nonce must be **32 randomly generated bytes**, encoded as lowercase hex. The example above is a format illustration, not a private dataset. Integers must lie between -1,000,000 and 1,000,000. Each model and dataset file must be at most 65,536 bytes. Prediction is `bias + sum(weight[i] * feature[i]) >= 0`; accuracy is `correct * 10000 // example_count` basis points.

Run an IPFS node and `KALLY_SERVICE_TOKEN=... uvicorn uploader:app`. Upload the model with `POST /v2/artifacts/model` and the dataset with `POST /v2/artifacts/dataset`, each as multipart `file` with `Authorization: Bearer <operator token>`. The service validates and pins the exact bytes, returning `{cid, sha256}`. Keep the dataset CID and bytes private until betting closes. The on-chain hash is the commitment; the CID is revealed to `resolve(dataset_cid)` after the deadline. The creator enters the model CID, model SHA-256, dataset SHA-256, and a public HTTPS IPFS gateway URL ending in `/ipfs/` in the Create Market form. Verify that the gateway can actually return the model bytes before deploying. The contract source is `contracts/KallyMarketV2.py`.

Each validator downloads both artifacts from the market's committed gateway, verifies the SHA-256 commitments, validates bounds, computes all predictions, and returns the score through GenLayer's equivalence principle. A 7-day timeout permits cancellation and stake refunds when resolution cannot complete. If the dataset is released early, anyone can learn the outcome early. The dataset curator knows it from the outset and can trade or withhold it. This trust model is suitable for a testnet demonstration only; a production prediction market needs a neutral, auditable dataset release and anti-insider mechanism. Availability of the public IPFS gateway and GenVM runtime support must be verified with a live V2 resolution before relying on it. As of 2026-10-08, `ipfs.io/ipfs/` and `dweb.link/ipfs/` returned HTTP 429 service-worker migration responses to direct fetches from this environment; do not rely on them without a successful direct test.

The existing `KallyMarket.py` deployment is V1 and remains unsafe for meaningful betting. V1 accepts caller-supplied predictions; V2 cannot upgrade its state or existing stakes.
